# The Little Hero’s Big Adventure 🐾
### Stationary VR Action Platformer | Meta Quest 3 | Unity
This repository demonstrates end-to-end VR game development, from system design and gameplay programming to optimization and asset integration.

## Project Overview
The Little Hero’s Big Adventure is a single-player, stationary VR action platformer developed in Unity and designed specifically for the Meta Quest 3.

### Core Gameplay Highlights

* Third-person Avatar-based traversal

* Timing-based jumping mechanics

* Reconfigurable game world with movable platforms

* Indirect combat via controller-based aiming

* AI-driven enemies with state-based behavior

* Short-session gameplay (~10 minutes) optimized for VR comfort

## Requirements

* Unity Hub

* Unity Version: Unity 2022 LTS (recommended)

* Android Build Support

* Android SDK

* NDK

* OpenJDK

* Meta Quest 3 with Developer Mode enabled

* USB-C cable or Oculus Link / Air Link
